## Inline-Code (accent)

Ein Beispiel für Inline-Code: `pnpm build` sollte einen leicht getönten Hintergrund haben
(`accent-100`/`dark:accent-900/40`) und farbigen Text (`accent-800`/`dark:accent-300`). Fahr mit der Maus über den
Code — die Backticks sollten erst beim Hover erscheinen, in `accent-400`/`dark:accent-500`.

## Codeblock (Shiki Dual-Theme + primary + success)

Der Copy-Button unten sollte im Hover `primary-500`/`dark:primary-400` zeigen. Nach dem Klick erscheint ein grüner
Haken in `success-600`/`dark:success-400`. Der Codeblock selbst sollte im Light Mode hell und im Dark Mode dunkel
sein (nicht in beiden Modi gleich dunkel).

```ts
function greet(name: string): string {
	return `Hallo, ${name}!`
}
```
